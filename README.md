# لُغَتي — العربية للأطفال

تطبيق PWA عربي بالكامل لتعليم الأطفال العربية الفصحى بطريقة تفاعلية.

## الميزات
- واجهة RTL عربية بالكامل
- الحروف والكلمات والجمل
- نطق عربي عبر Web Speech API
- تمارين الاستماع والتحدث والميكروفون
- XP ومستويات وسلسلة أيام وشارات
- قصة تفاعلية
- حفظ التقدم محلياً
- دعم العمل دون اتصال للموارد الأساسية
- PWA قابلة للتثبيت
- GitHub Pages عبر GitHub Actions

## التشغيل
```bash
npm install
npm run dev
npm run build
```

## الخصوصية والمصادقة
لا يوجد تسجيل دخول أو خادم أو رموز وصول في النسخة الحالية. التقدم محفوظ في جهاز المستخدم عبر localStorage. الميكروفون يُطلب فقط عند بدء تمرين الكلام، ولا يتم رفع التسجيل إلى خادم.
